# Event Management Web Application – Backend

Backend service for an Event Management platform that supports event creation, browsing, and ticket purchasing.

## Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Features
- Role-based access for Admin and Users
- Event creation, update, and listing APIs
- User registration and ticket booking
- Secure authentication and authorization using JWT
- RESTful API design with proper error handling
